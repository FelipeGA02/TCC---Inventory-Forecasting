Sistema de previsão de vendas · Floricultura Verde Perto · TCC 2026

[FELIPE · 12:00–12:45] Agora o sistema que leva tudo isso à empresa. O painel web, em React, conversa com uma API REST em FastAPI, com autenticação por JWT, senhas em bcrypt e o contrato documentado em OpenAPI. A API grava no banco PostgreSQL, no serviço Neon, e usa SQLite no desenvolvimento e nos testes. O serviço de previsão é chamado pela API em segundo plano ou por um script, ajusta os modelos em processos paralelos e grava as previsões, as métricas e o histórico no banco. O treino de produção leva cerca de setenta e cinco minutos, dentro do limite de duas horas que definimos como requisito. O back-end é um monólito modular em camadas, e a lógica de previsão fica num domínio que não depende de framework nem de banco, o que facilitou os testes: são cento e noventa e seis testes automatizados aprovados.
