Pergunta de pesquisa

“Como utilizar os dados históricos de vendas de uma floricultura para gerar, de forma sistemática e antecipada, previsões de demanda diária que apoiem o planejamento de compras?”

A loja continua decidindo a compra; o sistema informa quanto se espera vender.

[DANIEL · 2:10–2:35] Isso nos levou à pergunta de pesquisa do trabalho: como utilizar os dados históricos de vendas de uma floricultura para gerar, de forma sistemática e antecipada, previsões de demanda diária que apoiem o planejamento de compras? Um ponto de escopo, combinado com a empresa: o sistema não decide a compra. Ele informa quanto se espera vender em cada dia, com uma faixa de incerteza, e a decisão continua com a gestora.
