Apêndice · treinar previsões

Treino em segundo plano e notificações

  • Botão “Treinar previsões”, visível só para a gestora (perfil administrador)
  • Andamento série a série no sino; o painel continua utilizável
  • Sem dados novos desde o último treino, o pedido é dispensado (impressão digital SHA-256)
  • Avisos: vendas que a previsão ainda não usa e séries para usar com cautela

Base de demonstração com vendas fictícias

Apoio para perguntas. Cada treino fica registrado em forecast_jobs com a configuração, a versão do código, o período dos dados e as contagens de séries; cada série em series_models com ordem, métricas, diagnóstico dos resíduos e coeficientes. Na produção o treino roda por script, porque o plano gratuito do Render tem 512 MB de memória; com 12 processos levou 75 minutos (limite do RNF03: 2 horas).
